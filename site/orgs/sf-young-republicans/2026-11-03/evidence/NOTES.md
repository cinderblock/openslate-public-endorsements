## AGGREGATOR SOURCE ONLY — read this first

Every position in this bundle comes from **sfendorsements.com**, an
independent compilation of SF voter guides by Peter Xu
(https://sfendorsements.com/, source https://www.gitlab.com/peterxu/sf-endorsements).

website for the club:

- sfendorsements.com's "About the endorsers" section links the SF Young
  Republicans to https://www.sfyd.org/, which is the SF *Young Democrats*
  site (a copy-paste error on the aggregator).
- I also tried https://www.sfyr.org/ (a domain-parking "/lander" redirect),
  https://sfyr.com/, https://sfyoungrepublicans.org/,
  https://sfyoungrepublicans.com/ and
  https://www.sanfranciscoyoungrepublicans.com/; none resolved.
- A web search for the group's November 2026 endorsements found nothing.

The aggregator row has no "Has reasoning" link. Each position cites
`https://sfendorsements.com/` as `source`, and its statement quotes the
table cell. Verify against the club's own channels (social media or
newsletter) if possible before publishing.
