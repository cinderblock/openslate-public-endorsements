# NOTES — Congressional Progressive Caucus PAC, Nov 3 2026 California general (California picks only)

The CPC PAC is a national organization. This bundle holds only its
California picks for the November 3, 2026 general election.

## Sources

- https://weareprogressives.org/ (the PAC's site; progressivecaucuspac.com
  no longer resolves). Under "PAC ENDORSEMENTS" the home page has a grid of
  endorsement graphics with no text and no links. All 27 candidate graphics
  were checked. Four are Californian, and their text was transcribed (see
  `weareprogressives-endorsement-graphics.md`). The WordPress REST API
  returns 403, so no text version was available. Hence
  `attribution.mode: transcribed`.
- Cross-check: https://bluevoterguide.org/endorser-org/Congressional_Progressive_Caucus_PAC/CA/3022
  (aggregator) lists the same four California House candidates for the
  "General on November 3, 2026". It was used only to confirm, not as a
  source for any position.

## Extracted: 4 positions

- CD 1 Mike McGuire, CD 14 Aisha Wahab, CD 22 Randy Villegas, CD 38 Hilda
  Solis. All four are November finalists per existing bundles.

## Review flags

- The statements are transcriptions of image text. The graphics say
  "PROGRESSIVE CAUCUS ... ENDORSEMENT", not "PAC". They are on the PAC's
  site under the "PAC ENDORSEMENTS" heading.
- `source` is the home page because the graphics don't link to individual
  press releases.
